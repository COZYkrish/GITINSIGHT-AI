# Analysis Service Core Architecture (`analysis.service.ts`)

The central coordination engine powering all intelligence features.

## Primary Methods
- `generateDeveloperDNA(userId)`: Synthesizes engineering archetype and radar metrics.
- `generateRecruiterReport(userId)`: Produces hiring executive summaries and evaluation badges.
- `generatePortfolioScore(userId)`: Computes multi-pillar developer score.
- `generateWrappedReport(userId, year)`: Builds retrospective metrics.
- `generateCareerReport(userId, targetRole)`: Evaluates market readiness.
