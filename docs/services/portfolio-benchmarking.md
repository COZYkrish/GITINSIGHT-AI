# Portfolio Score Benchmarking & Percentiles

Scores are normalized against global GitHub developer benchmarks:
- Top 5%: Score `90 - 100` (Expert)
- Top 20%: Score `75 - 89` (Advanced)
- Top 50%: Score `55 - 74` (Intermediate)
- Developing: Score `< 55`

Percentile rank is recalculated periodically to reflect growing community baselines.
