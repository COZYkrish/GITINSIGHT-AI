# API Reference: Analysis Routes (`analysis.routes.ts`)

## Triggers
- `POST /api/analysis/dna`: Trigger Developer DNA evaluation
- `POST /api/analysis/recruiter`: Trigger Recruiter Report generation
- `POST /api/analysis/portfolio`: Trigger Portfolio Score calculation
- `POST /api/analysis/career`: Trigger Career Readiness assessment
- `POST /api/analysis/wrapped`: Trigger GitHub Wrapped compilation
