# Prompt Engineering Guidelines

1. **System Persona**: State the exact role (e.g., "You are an elite principal engineer and technical hiring bar-raiser").
2. **Strict Output Framing**: "Return ONLY valid JSON matching this schema. Do not enclose in markdown blocks unless requested."
3. **Evidence-Based Evaluation**: Require the model to cite concrete repositories, language percentages, and commit metrics in its outputs.
4. **Tone Standards**: Professional, constructive, analytical, and encouraging.
