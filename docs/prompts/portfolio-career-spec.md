# Prompt Specifications: Portfolio Score & Career Readiness

## 1. Portfolio Prompt (`portfolio.prompt.ts`)
Synthesizes repository impact, documentation maturity, and engineering hygiene into an aggregated portfolio score (0-100) and highlights top showcase projects.

## 2. Career Readiness Prompt (`career.prompt.ts`)
Maps developer's current tech stack against contemporary industry job market requirements, calculating readiness percentages for roles like "Full-Stack Engineer", "Backend Specialist", or "DevOps Engineer".
