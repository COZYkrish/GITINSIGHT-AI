# Prompt Specifications: Readme Analyzer & Repository Compare

## 1. Readme Analyzer (`readme.prompt.ts`)
Scores repository READMEs against standard criteria:
- Project overview & value proposition
- Quickstart / installation instructions
- Architecture overview & configuration guide
- Contributing guidelines & license

## 2. Repository Compare (`repositoryCompare.prompt.ts`)
Performs head-to-head comparisons of two codebases analyzing complexity, test density, and maintenance activity.
