# GitInsight AI Prompt Catalog

This directory documents the 12 specialized AI prompt templates used throughout GitInsight AI:

1. `developerDNA.prompt.ts` — Core archetypes & radar chart metrics
2. `recruiter.prompt.ts` — Candidate hiring summary & badges
3. `portfolio.prompt.ts` — Overall portfolio score & showcase projects
4. `career.prompt.ts` — Seniority benchmarking & skill gap roadmaps
5. `wrapped.prompt.ts` — Annual developer achievements review
6. `timeline.prompt.ts` — Career milestone timeline
7. `readme.prompt.ts` — README analysis & grading
8. `repositoryCompare.prompt.ts` — Head-to-head repository comparison
9. `linkedin.prompt.ts` — Social post generator
10. `resume.prompt.ts` — ATS-friendly bullet points
11. `mentor.prompt.ts` — Actionable engineering coaching
12. `portfolioGenerator.prompt.ts` — Web portfolio bio and project highlights
