# Prompt Specification: Recruiter Report (`recruiter.prompt.ts`)

Evaluates candidate code through the lens of technical recruiters and engineering managers.

## Output Attributes
- `executiveSummary`: 2 paragraphs summarizing technical positioning
- `seniorityLevel`: Recommended hiring bracket (Junior, Mid, Senior, Lead)
- `keyStrengths`: 3-5 bulleted strengths with evidence
- `growthOpportunities`: 2-3 constructive development points
- `interviewQuestions`: 3 targeted behavioral & technical questions based on the candidate's real codebase.
