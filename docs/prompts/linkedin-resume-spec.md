# Prompt Specifications: LinkedIn & Resume Generation

## 1. LinkedIn Generation (`linkedin.prompt.ts`)
Converts repository accomplishments and release milestones into engaging LinkedIn thought leadership posts formatted with emojis, hashtags, and call-to-actions.

## 2. Resume Builder (`resume.prompt.ts`)
Transforms GitHub activity, language proficiencies, and top projects into clean ATS-compliant resume work experience bullet points formatted with strong action verbs.
