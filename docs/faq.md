# Frequently Asked Questions (FAQ)

### 1. Does GitInsight AI read my private code?
No. GitInsight AI only inspects repository metadata (languages, commit cadence, star counts, pull requests). We never clone or persist proprietary source code files.

### 2. Can I share my Developer DNA publicly?
Yes. Turn on "Public Profile" in `/settings` to generate a shareable vanity link (`/u/your-name`).

### 3. How often can I sync repositories?
Free tier accounts can synchronize repositories once every 5 minutes.
