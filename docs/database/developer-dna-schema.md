# MongoDB Schema: DeveloperDNA Model (`DeveloperDNA.ts`)

Represents the core AI-evaluated developer profile.

## Archetype Categories
- **Architect**: High structural modularity, clear separation of concerns, comprehensive documentation.
- **Speed Demon**: Rapid feature deployment cadence, frequent small commits, active PR merge volume.
- **Craftsman**: High test coverage, strict typing, clean design patterns, lint adherence.
- **Explorer**: Diverse technology stack, multi-language versatility, frequent open-source experimentation.
- **Specialist**: Deep focused expertise in a single ecosystem (e.g., Rust, Distributed Systems, ML).

## Evaluated Dimensions (Scale 0-100)
- `codeQuality`: Structural soundness and clean architecture
- `consistency`: Commit distribution regularity across weeks
- `architecture`: Systems design and modularity
- `velocity`: Delivery cadence and PR turnaround
- `collaboration`: PR reviews, issue conversations, and documentation
