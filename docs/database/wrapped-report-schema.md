# MongoDB Schema: WrappedReport Model (`WrappedReport.ts`)

Annual developer review celebrating accomplishments, milestones, and personal coding habits.

## Schema Properties
- `year`: Numerical calendar year (e.g., 2026)
- `totalCommits`: Total commits authored within the calendar year
- `mostProductiveDay`: Day of week with highest commit frequency
- `longestStreak`: Consecutive days with at least 1 commit
- `topLanguage`: Most written language by byte count
- `busiestMonth`: Month with peak commit volume
- `topRepositories`: Top 3 repositories by activity and impact
- `funFacts`: Array of humorous, encouraging AI-generated developer quirks.
