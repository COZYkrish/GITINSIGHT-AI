# Recruiter Evaluation Rubric & Badge Allocation

## Automated Badge Criteria

| Badge ID | Badge Name | Minimum Criteria |
|----------|------------|------------------|
| `POLYGLOT` | Polyglot Engineer | 3+ languages with > 50,000 bytes each |
| `OSS_CONTRIBUTOR` | Open-Source Citizen | 5+ merged PRs to external public repositories |
| `PRODUCTION_READY` | Production Veteran | Dockerfile, CI workflow, and test suites detected |
| `CONSISTENT_MAKER` | Consistent Maker | 40+ active coding weeks in the trailing 12 months |
| `HIGH_IMPACT` | Community Impact | 50+ aggregate stars across public repositories |
| `CLEAN_ARCHITECT` | Clean Architect | Strict TypeScript, ESLint, and modular domain design |
