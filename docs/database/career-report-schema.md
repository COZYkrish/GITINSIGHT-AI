# MongoDB Schema: CareerReport Model (`CareerReport.ts`)

Career progression analysis, market readiness index, and tailored skill gap roadmap.

## Key Attributes
- `targetRole`: Desired engineering role (e.g., "Senior Full-Stack Engineer")
- `readinessScore`: Numerical score (0-100) indicating current match to target role
- `masteredSkills`: Skills proven through committed code
- `missingSkills`: High-demand industry skills absent from current repos
- `actionPlan`: Phased 3-month action plan with suggested project ideas to bridge gaps.
