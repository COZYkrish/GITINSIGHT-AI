# Responsive Layout Breakpoints & Mobile Navigation

- `sm: 640px` — Mobile devices; single-column stacked radar cards.
- `md: 768px` — Tablet; dual-column metrics and collapsible sidebar.
- `lg: 1024px` — Desktop; permanent navigation drawer and multi-column analytics grid.
- `xl: 1280px` — High-DPI screens; expanded radar canvas and code snippet panels.
