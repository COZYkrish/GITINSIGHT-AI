# Three.js 3D SolarSystem Integration (`components/three/SolarSystem.tsx`)

The landing page and portfolio pages feature an interactive 3D solar system built with `@react-three/fiber` and `@react-three/drei`.

- The Central Star represents the Developer Identity.
- Orbiting Planets represent primary technology proficiencies (TypeScript, Python, Go, Docker) scaled by language byte size.
- Includes automatic frame budgeting to maintain 60 FPS on mobile and low-power devices.
