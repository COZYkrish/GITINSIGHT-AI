# DeveloperDNA Archetype Threshold Tuning & Percentile Curves

## Archetype Categories
GitInsight AI assigns one of 6 primary archetypes based on normalized metric vectors:
1. **The System Architect**: High modularity, multi-repo commit dispersion, infrastructure files.
2. **The Code Crafter**: Consistent commit cadence, clean test-to-code ratios.
3. **The Polyglot Explorer**: 4+ programming languages with balanced byte weights.
4. **The Sprinter**: High burst commit clusters, rapid prototype lifecycle.
5. **The Community Steward**: Significant PR review activity, issue resolution.
6. **The Specialist**: >85% concentration in a single language/stack.
