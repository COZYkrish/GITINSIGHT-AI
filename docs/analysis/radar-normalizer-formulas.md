# Radar Chart Normalizer Formulas & Dimension Bounds

## Dimensions (0 - 100 Scale)
The Developer DNA radar chart visualizes 6 core dimensions:
- `velocity`: Commits per active week (max capped at 30).
- `consistency`: Shannon entropy of weekly commit distribution.
- `collaboration`: Pull request reviews and issue discussions.
- `impact`: Star counts, forks, and external contributor commits.
- `diversity`: Language Shannon diversity index.
- `craftsmanship`: Presence of CI workflows, tests, and documentation.
